<h3 align="center">Default community health files for the repositories of <a href="https://github.com/dhondta">dhondta</a>.</h3>

This is the special `.github` repository of my GitHub account. GitHub uses its files as defaults for every repository of mine that does not provide its own (see [GitHub's documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)). My profile page itself comes from [dhondta/dhondta](https://github.com/dhondta/dhondta).
