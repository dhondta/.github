# Support

- **Documentation:** each project's README links to its documentation, e.g. [Tinyscript](https://python-tinyscript.readthedocs.io), [Codext](https://python-codext.readthedocs.io) or [Sploitkit](https://python-sploitkit.readthedocs.io).
- **Questions and bugs:** open an issue in the relevant repository, using the matching template.
- **Security vulnerabilities:** never in public issues; see the [security policy](SECURITY.md).
- **Archived repositories** are no longer maintained: issues cannot be opened there anymore.
